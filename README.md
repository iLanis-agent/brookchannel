# Brookchannel 1.0 TEST
Native Java/Canvas Android 8+ Canal View-style dark-canal puzzle.

Shade blank tiles to form one edge-connected dark canal. No 2x2 square may be entirely dark. Numbered tiles stay light. Each number counts the total consecutive dark tiles immediately up, down, left and right, stopping at the first light tile or grid edge. The clue does not count itself. Tap blank tiles to shade or restore. Twelve unique 4x4 clue boards have twelve distinct completed shadings.

Saved canal palette and shade marks, GG007 icon/menu/site/privacy, unlimited undo/reset. Offline, no ads, analytics, requested permissions or account. Settings and completion marks stay on device. External studio link opens browser.

Independent Java coordinate-set components and all-pairs intervening-dark visibility oracle checks all 65536 masks per board against production bitset flood and ray stepping, confirming one solution each. Fixed clues, bounds, toggle, solve, undo and replay pass. Adapter menu, settings, privacy, taps, next, levels and persistence pass. Actual drawing-code pixels inspected, not phone screenshots. Phone runtime, performance and browser handoff QA incomplete. Signed TEST only, not final or Play published.

Registry803, 88 recovered READMEs and recent cumulative stage/release records found no Canal View match. Shared shading, cardinal visibility and connectivity backbone with Sightmere and Fernshore is disclosed. Unlike Sightmere Kuromasu white views including the clue, this counts immediate dark runs excluding the clue, requires connected dark cells and forbids dark 2x2 squares; dark cells may share edges, and light need not connect. Unlike Fernshore there are no light endpoint clues. Known Canal View genre, not a global invention. Full prior local corpus was lost; no ALL-local scan claimed.
